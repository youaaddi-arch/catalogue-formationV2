Instructions de configuration
1. Fichier credentials Google

Placez le fichier JSON du Service Account Google dans le dossier de l'application sous le nom credentials.json, ou définissez la variable d'environnement GOOGLE_CREDENTIALS_PATH.

2. Fichier Excel CONSTATS EP

Placez le fichier EP & CONTROLE MARS 26.xlsx dans le dossier de l'application, ou définissez la variable d'environnement EXCEL_PATH.

3. Variables d'environnement
export GOOGLE_CREDENTIALS_PATH=/chemin/vers/credentials.json
export EXCEL_PATH=/chemin/vers/EP\ &\ CONTROLE\ MARS\ 26.xlsx
export FLASK_DEBUG=True
export SECRET_KEY=votre-cle-secrete
4. Modification des paramètres

Pour modifier les IDs de Drive, la liste des apprentis ou les pièces à vérifier, éditez le fichier config.py.
